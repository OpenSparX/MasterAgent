# 系统概述

MasterAgent-v2 是面向车载智能交互的 C++17 参考实现。它从文本接入开始，覆盖请求规范化、短期记忆、确定性技能、Prompt 组装、两阶段 Mock 推理、任务编排、MCP 原子服务、Agent 调度、结果返回、数据日志与异常治理。

## 1. 设计目标

- 确定性优先：规则能够闭合时不调用模型。
- 模型受控：模型只能输出封闭 JSON 协议，不能直接执行能力。
- 副作用可靠：提交、查询、终态、未知和对账分离。
- 优先级可验证：P0、P1、P2 使用统一类型和比较规则。
- 抢占安全：只在安全点协作抢占，不终止线程，不伪造成功。
- 恢复失败关闭：无法确认副作用时进入 `Unknown`，禁止盲目重试。
- 可审计：关键事件、异常、因果身份和耐久等级可追溯。

## 2. 默认执行链

```text
TextInput
  -> InteractionLayer
  -> AgentService
  -> Preprocess + Memory
  -> Skill / Prompt / Intent
  -> direct ASK|REPLY|FAIL
     or Task DAG -> Orchestrator
          -> AtomicService (MCP Tool)
          -> AgentDispatch (external sub-Agent boundary)
          -> InferenceFramework (Mock model)
  -> TurnResult
  -> DataLog + Exception
```

## 3. 核心模块

| 模块 | 职责 |
| --- | --- |
| Interaction | 校验输入，生成稳定请求、追踪和会话轮次 |
| AgentService | 协调一次用户 Turn，不拥有下游业务状态 |
| Preprocess | 请求校验、UTF-8 清洗、参数/时间规范化，以及独立的运行状态能力发现和按需查询 |
| Memory | 对接已交付的短期记忆库 |
| Skill | 确定性意图和参数闭合 |
| Prompt | 组装受控模型输入和摘要 |
| Intent | 管理确定性路径与最多两阶段模型协议 |
| Orchestrator | 校验 DAG、调度节点、聚合计划状态 |
| AtomicService | MCP Tool 注册、执行、幂等和对账 |
| AgentDispatch | 管理外部子 Agent 调度契约 |
| Inference | 管理模型作业、KV、优先级和安全抢占 |
| DataLog | 事件、审计、trace、耐久和隐私边界 |
| Exception | 异常归一、分组、升级、恢复和应急环 |
| Runtime | 创建、注入、启动和关闭模块 |

## 4. 默认部署

默认交付为一个进程、一个核心库和一个应用入口。可选 IPC 代码位于 `transport/ipc`，默认不参与构建。业务接口不依赖传输方式，因此后续增加进程隔离时不需要改变任务、优先级或恢复语义。
