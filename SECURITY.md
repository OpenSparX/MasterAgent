# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | ✅ Current          |
| < 0.3   | ❌ Not supported    |

## Reporting a Vulnerability

If you discover a security vulnerability in OAK, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Email: security@opensparx.dev
3. Include: description, reproduction steps, and impact assessment.

We will acknowledge receipt within 48 hours and provide a fix timeline within 7 days.

## Scope

Security-sensitive areas of OAK include:
- On-device model inference isolation
- Agent sandboxing and permission boundaries
- IPC transport authentication
- DP-SGD privacy guarantees in on-device learning
