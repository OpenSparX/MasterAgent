【适用场景】
当用户说“还是老样子”“按平时来”“按我习惯那个”这类基于历史偏好的表达时，使用本 Skill。

【触发信号】
用户表达包含但不限于：
1. 还是老样子。
2. 按我平时那个习惯。
3. 按平时来。
4. 和上次差不多就行。

【目标】
识别用户是在引用历史偏好、默认习惯还是过去满意的某种安排，并输出复用建议或澄清问题。

【输入关注点】
1. 用户当前引用的是哪一类偏好。
2. 当前场景是否足以判断“老样子”指代什么。
3. 是否存在多个可能的历史习惯。
4. 当前场景是否适合直接复用旧偏好。

【执行步骤】
1. 判断 query 是否在引用历史偏好。
2. 识别这类偏好可能属于行程、音乐、空调、提醒、通知还是其他场景。
3. 如果指代不清，先缩小到最可能的偏好类型并提出澄清。
4. 如果上下文足够明确，则输出“复用历史偏好”的建议性描述。
5. 明确说明当前理解到的是哪类偏好。

【分支处理】
1. 如果存在多个候选偏好，优先澄清，不直接猜。
2. 如果用户在当前会话已经明确过偏好，可直接承接。
3. 如果当前场景和历史习惯明显不一致，应提示不建议直接复用。

【约束】
1. 不假设系统一定有可用记忆。
2. 不把模糊偏好解释成过于具体的执行动作。
3. 输出时要区分“已确认复用”和“推测可能是”。

【输出要求】
输出至少包括：
1. 当前理解的偏好类型。
2. 是否可直接复用。
3. 如果不能直接复用，需要用户补充什么。

【终止条件】
当已经识别偏好类型并给出复用建议或澄清问题后结束。

【失败与回退】
如果完全无法判断“老样子”的指代对象，则回退为澄清型问句。
