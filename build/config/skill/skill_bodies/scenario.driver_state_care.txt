【适用场景】
当用户表达疲劳、困倦、紧张、状态不好、想稳一点或需要主动提醒时，使用本 Skill。

【触发信号】
用户表达包含但不限于：
1. 我有点困帮我盯着点。
2. 我心里有点慌找个地方停一下。
3. 提醒我稳着点。
4. 我现在状态不太好。

【目标】
围绕驾驶安全与主动关怀，输出更稳妥的建议、提醒策略或短暂停靠建议。

【输入关注点】
1. 用户是疲劳、紧张还是注意力下降。
2. 是否仍在驾驶中。
3. 用户更需要提醒、安抚、停靠建议还是节奏放缓。
4. 是否存在立即风险。

【执行步骤】
1. 判断用户描述的是哪类驾驶状态风险。
2. 优先输出安全导向建议，如放缓节奏、减少打扰、寻找安全停靠点。
3. 如果用户提到“停一下”，将短暂停靠视为强候选建议。
4. 如果状态描述较重，应以保护性语言表达，不进行轻率鼓励。
5. 保持输出简洁明确，避免在驾驶中造成额外认知负担。

【分支处理】
1. 困倦类表达优先建议休息、提神、减少刺激信息。
2. 紧张或慌乱类表达优先建议降低节奏、稳定情绪、必要时短暂停靠。
3. 若用户同时涉及复杂任务，应建议先安全稳定后再继续。

【约束】
1. 安全优先于效率与便利。
2. 不对明显风险状态做乐观淡化。
3. 避免长篇复杂输出，减少驾驶干扰。

【输出要求】
输出至少包括：
1. 当前识别到的状态风险。
2. 一到两条最重要的建议。
3. 如有必要，建议先停靠或休息。

【终止条件】
当已经给出明确的安全建议后结束。

【失败与回退】
如果无法判断具体风险类型，则至少回退为通用的安全优先建议。
